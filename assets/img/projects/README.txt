Drop project photos/renders here, e.g.:

    rmse23-chassis.jpg
    iem26-suspension-cad.png

Then in data/content.js, find that project's "image" field and point it at
the new file, e.g.:

    image: "assets/img/projects/rmse23-chassis.jpg",

Recommended: 1280x800px (16:10), under 500KB, .jpg for photos / .png for
CAD renders and screenshots. Until you add a real image, the project keeps
using the dashed placeholder graphic so nothing looks broken.
