Product photos shown alongside a Work Experience card (e.g. Tesla's
Powerwall). Wired up via experience[].productImage + productCaption in
data/content.js — set both to null to hide the image for that card.

tesla-powerwall.jpg — Tesla Powerwall 2, from Wikimedia Commons
(https://commons.wikimedia.org/wiki/File:Tesla_Powerwall_2.jpg), released
under CC0 (public domain) by the uploader. Resized/compressed for web use.

No Range Rover Electric photo is included for the JLR card: it's still an
unreleased, camouflaged prototype, so every photo of it currently in
circulation is a copyright-restricted press image, not freely licensed.
Once you have a photo you're personally cleared to use (e.g. from JLR's
own media newsroom under their press-use terms, or a photo you took
yourself), drop it here and set jlr's productImage/productCaption in
data/content.js.

General rule for adding more of these later: don't pull a random image off
the web without checking its license. Wikimedia Commons file pages state
the license clearly; a company's own press/media page usually states its
terms of use for press photos.
