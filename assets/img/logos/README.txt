tesla.svg and jaguar.svg are simplified monochrome brand marks from the
Simple Icons project (https://simpleicons.org, CC0-licensed icon artwork —
the underlying trademarks still belong to Tesla, Inc. and Jaguar Land Rover
respectively). Used here purely to indicate past employment, the same way
LinkedIn shows a company logo next to a job entry.

Log9 Materials has no icon in that library, so its entry on the site uses
a plain text wordmark instead of a logo file — see data/content.js
(experience[].logo is left empty for Log9, and main.js falls back to a
styled text badge).

If you want to swap in official, higher-fidelity logo files later (e.g.
from each company's own press/brand page), just drop the new SVG/PNG here
and update the matching `logo` path in data/content.js.
